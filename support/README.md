# Capelo

**Word Game**

A fast, addictive word game. Swipe across a letter grid to form words, trigger chain explosions, and chase the high score.

## Features

- Endless 7×7 letter grid
- Bomb chains and time bonuses
- 4 languages (English, French, Spanish, Portuguese)
- Global leaderboard
- Built-in word definitions

## Available On

- iOS 18.6+
